## 🚀 Overview

**Fitnplus** is a modern fitness and health tracking application designed to help users monitor their daily activity, workouts, health metrics, progress, and fitness goals through a clean and interactive interface.

The application focuses on:

* Simple navigation
* Personalized health insights
* Visual progress tracking
* Workout management
* Activity monitoring
* Community challenges
* Responsive UI
* Smooth micro-interactions
* Light / Dark theme support

This project is the **actual coded application**, separate from the Fitnplus promotional website.

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Fitnplus.git
```

### 2. Open the project

```bash
cd Fitnplus
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will provide a local development URL such as:

```text
http://localhost:5173
```

---

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
